# Garden TSS - React Application

A React + Vite application for Garden Technical Secondary School (TSS) with user authentication, admin dashboard, and content management.

## Features
- User authentication (login, signup, password reset)
- Admin dashboard with user management
- Content management system
- Responsive design with sidebar navigation
- Programs, Team, Contact, and Admissions pages

## Setup
```bash
npm install
npm run dev
```

## Backend
Requires Node.js server running on port 3000 (see `/server` directory)
