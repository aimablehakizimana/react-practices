
# Garden TSS - Technical & Vocational Education Platform

A modern React-based web platform for Garden Technical Secondary School (Garden TSS), showcasing programs, team, and admissions information.

## Features

- **Responsive Design**: Works seamlessly across all devices
- **Professional UI**: Modern interface with smooth animations
- **Navigation**: Sidebar navigation with hamburger menu
- **Authentication**: Login system with logout functionality
- **Multiple Pages**: Home, About, Programs, Team, Contact, Admissions, Careers

## Programs Offered

- 💻 Software Development
- 🏗️ Building Construction  
- 🚗 Automobile Technology

## Tech Stack

- React 19.2.4
- React Router DOM
- Vite
- CSS3 with modern styling

## Getting Started

```bash
npm install
npm run dev
```
